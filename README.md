# SLE777_RNAseq_Analysis

RNA-seq analysis project for SLE777.

## Project description

This repository contains an RNA-seq analysis workflow completed for SLE777. The analysis covers the workflow from sequencing data processing through to gene expression analysis, differential expression and biological interpretation.

## Main file

- `SLE777_RNAseq_report.Rmd` — R Markdown report containing the RNA-seq analysis for Weeks 3–10.

## Running the report

Open `SLE777_RNAseq_report.Rmd` in RStudio and knit the document to HTML.

The supporting result files and required R packages must be available for the report to run successfully.

## Version control

Git and GitHub are used to record changes to the analysis and maintain a reproducible history of the project.
